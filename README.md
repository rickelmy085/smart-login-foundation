# Smart Login Foundation

Construa a Etapa 1 do MVP B-Smart Copilot conforme especificado: design system global com tema claro/escuro persistido, componentes reutilizáveis e acessíveis, tela de login corporativa split screen responsiva e autenticação simulada (RE 123456, senha demo123), redirecionando após sucesso para uma rota futura vazia. Não implemente Dashboard, sidebar, chat, IA, histórico, RAG ou integrações externas.

This project was built with [Lovable](https://lovable.dev).
